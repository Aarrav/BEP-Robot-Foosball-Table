# Experiments

- One folder per experiment, named `YYYY-MM-DD_short-name` (e.g. `2026-11-20_ir-raw-dump`).
- Start by copying `_template/` and filling in its README.
- Raw data stays untouched. Processed results and plots go next to it.
- Do not commit large files (>50 MB). Store them elsewhere and note in the experiment's README where they are.
